# Sistema de Alquiler de Vehículos 

Proyecto desarrollado en Java como trabajo académico, utilizando programación orientada a objetos (POO). El sistema permite gestionar usuarios y realizar operaciones relacionadas con el alquiler de vehículos.

## Tecnologías utilizadas
- Java
- Eclipse IDE

## Conceptos y características
- Programación orientada a objetos (POO).
- Herencia y polimorfismo mediante redefinición de métodos (`@Override`).
- Registro de usuarios en memoria.
- Alquiler y devolución de vehículos.
- Donación de vehículos.
- Historial de registros y operaciones.

## Ejecución
Proyecto preparado para importarse y ejecutarse desde Eclipse IDE.

**Nota:** Los usuarios y registros se almacenan en memoria, por lo que los datos no se conservan al cerrar o reiniciar el programa.

## Autor
Proyecto desarrollado con fines educativos para practicar Java y los principales conceptos de la programación orientada a objetos.
